reading-the-wind / OOπ・TTT・E式

磁場閉じ込め・核変換・直接電力変換

トカマクの「できない」を別の形で「できる」に転換する
ハイブリッドエネルギーシステムの構造読解と構想

0. 問いの起点

トカマク型核融合はTTT理論で解析した結果、「商業炉としての連続運転は到達不能」と判明した。しかし、トカマクが培ってきた磁場閉じ込め技術は、それ自体が無価値ではない。分裂の中性子制御と組み合わせ、核変換と直接電力変換を統合したハイブリッドシステムは実現可能ではないか。

これは「閉じ込める」と「出す」の矛盾を、矛盾として終わらせるのではなく、「出すものを別の目的の入力に使う」という構造的転換である。OOπの言葉で言えば、押した面（中心のプラズマ）の裏面（外周の中性子・荷電粒子）を「廃棄物」ではなく「資源」として読み直す。

核心の洞察：トカマクの「失敗」は、プラズマの「炉」としての失敗である。しかし、プラズマを「中性子源」として読めば、zZ（排熱・排気）の問題は核変換の「駆動力」に転換する。問題の定義を変えることで、解の空間が開く。

1. 既存の研究地図 — 何がすでに存在するか

この構想は空想ではない。複数の研究分野がすでに個別に存在している。

1.1 核融合-核分裂ハイブリッド炉

核融合炉のD-T反応が発生する14MeV中性子を、周囲の核分裂燃料ブランケットで利用する概念は、1960年代から研究されている。Weston M. Staceyの著書（2022年）やORNLのFusion-Fission Hybrid Pebble Bed Reactor、ロシアのクルチャトフ研究所の系統研究など、実績がある。

主な応用先は三つ：

  • 核燃料の増殖：Thorium-232や劣化ウラン（U-238）をU-233やPu-239に変換
  • アクチノイドの核変換：長寿命核種（Np-237、Am-241、Cm-244等）を短寿命化
  • トリチウム増殖：Li-6 + n → T + He-4

1.2 加速器駆動核変換システム（ADS）

日本では1988年から「オメガ計画」として核変換研究が進められてきた。加速器で陽子を重金属ターゲットに当ててスパラーション中性子を発生させ、長寿命核種を核変換するADS（Accelerator Driven System）は、核融合を使わずに中性子源を作る別のアプローチである。

1.3 直接エネルギー変換（DEC）

核融合生成物の荷電粒子（アルファ粒子など）の運動エネルギーを、熱サイクルを介さず直接電力に変換する技術。1960年代にLLNLのR. F. Postが提唱し、神戸大学の竹野浩正らがCUSP-DEC（カスプ型直接エネルギー変換器）の模擬実験を進めている。

D-³He反応やp-B反応のような「先進燃料」では、生成物が荷電粒子のみ（中性子が少ない）なので、DECの効率が高まる。熱サイクル（カルノー効率40%程度）を介さず、60-80%の効率で電力換が可能という理論的見込みがある。

重要な発見：これら三つの分野（ハイブリッド炉・ADS・DEC）は、今まで別々に研究されてきた。しかしTTT理論で読めば、これらは一つの統合システムの「部品」である。分断された研究領域の間に、統合の可能性が眠っている。

2.2 ハイブリッドシステムへの構造転換

トカマクを「炉」から「中性子源」に再定義すると、変数の係数が変わる。

変数ハイブリッドシステム係数の変化
xX磁場閉じ込め（中性子源として）Q>1不要。中性子が出ればよい。係数の要求が緩和
yYプラズマ圧力→中性子産额「炉」としての高圧不要。ELMの影響が減少
zZ中性子をブランケッで吸収・変換ダイバータ排熱→ブランケット排熱に転換。材料問題は残るが、幾何学的自由度が増す

vV中性子の輸送（ブランケット内）プラズマ輸送→固体/液体中の中性子輸送。より予測可能
wW中性子→核変換→熱→電力（またはDEC）エネルギー変換経路が複数化
構造的転換の核心：トカマクのzZ係数≒0（排熱不能）は、「炉」としてのzZの話である。中性子源としてのzZは、ブランケットの設計次第で係数を上げられる。問題の定義を変えることで、zZの「有無」ではなく「設計可能なパラメータ」になる。

3. 統合システムの構想 — 三つの層

層1：中性子源層（トカマクまたは代替）

役割

14MeVの高速中性子を大量に発生させる。Q>1（自己点火）は不要。外部熱で中性子を出せばよい。

代替案

トカマクにこだわる必要はない。球状トカマク（ST）、磁気ミラー、Zピンチ、あるいは加速器駆動のスパラーション中性子源でも代替可能。ADSの陽子加速器は技術的に成熟している。

層2：核変換・核分裂層（ブランケット）

役割

中性子を吸収し、二つの機能を同時に果たす。

  • 長寿命核種の核変換：MA（マイナーアクチノイド：Np, Am, Cm）を短寿命核種または安定核種に変換。日本の使用済燃料に含まれるMAは約数十トン。核変換で数百年の管理が数年〜数十年に短縮できる。
  • 核分裂によるエネルギー生成：ブランケット内の核分裂燃料（Th劣化ウラン）が核分裂し、熱を発生。これが実際の「発電」の主体になる。

幾何学的自由度

トカマクの第一壁はドーナツ状で排熱の自由度が極めて低い。ブランケットはトカマクの外側に配置できるため、冷却路の設計自由度が大幅に向上する。zZの幾何学的制約が緩和される。

層3：直接電力変換層（DEC）

役割

熱サイクルを介さず、荷電粒子の運動エネルギーを直接電力に変換する。

適用可能性

D-T反応では中性子が80%のエネルギーを持つため、DECの効果は限定的。しかし、以下の経路でDECは有効：

  • 核分裂層で生成されるベータ崩壊電子やフィッション_fragmentの荷電成分
  • ブランケット内のイオン化放射線による荷電粒子対生成
  • トカマクから漏出するアルファ粒子やイオンの運動エネルギー（直接回収）

効率の意味

熱サイクル（カルノー効率〜40%）を介さないDECは、理論上60-80%の効率が可能。これはwW（エネルギー移流）の散逸を大幅に減らす。トカマク単体の「Q<1」という問題は、エネルギー変換効率の向上で相殺できる。

4. E式による動的記述 — iIの転換

トカマク単体ではiI（潜在量）が破壊的にrRに転換していた。ハイブリッドシステムでは、この構造が変わる。

潜量（iI）トカマク体での転換ハイブリッドシステムでの転換
磁気ひずみの蓄積崩壊（disruption）→壁破壊崩壊→中性子源停止。核変換層は別系統で継続可能
壁材料への水素・ヘリウム吸蔵再循環→燃料純度低下ブランケット料は定期交換可能。hH（前歴）を管理できる
中性子照射損傷の累積炉の寿命終了（不可逆）ブランケットモジュールは交換可能。hHを「リセット」できる
長寿命核種の存在（該当なし）核変換で短寿命化。iIが「処理される」方向に転換
動的転換の核心：トカマクのiIは「蓄積→破壊」の一方通行だった。ハイブリッドシステムでは、iIを「資源」として取り出し、別の層で「処理」する循環構造になる。これはdD（散逸）の不可逆性を、循環の中に組み込むことで緩和する。気象で言えば、「積乱雲のエネルギーを別の場所で利用する」構造だ。

5. 安全性の構造 — Tri構造の読み直し

原子力の安全性は、従来「炉心の冷却・制御棒・格納容器」のTri構造で語られてきた。しかし福島以降、このTri構造の限界が明らかになった。

ハイブリッドシステムの安全性構造

従来のTriハイブリッドシステムの新Tri
炉心の冷却中性子源の停止（プラズマ消滅は即座）
制御棒ブランケットのモジュール化・分離
格納容器核変換による長寿命核種の減少（本質的安全性）

核融合-核分裂ハイブリッドの安全性の核心は、「臨界事故が起きにくい」ことにある。核融合中性子源は外部駆動型であり、プラズマが消えれば中性子が出なくなる。核分裂ブランケットは「自己点火」しないsubcritical系に設計できる。制御棒がなくても、中性子源を止めれば核分裂が止まる。

福島の教訓は「Tri構造の一つが壊れると連鎖的に崩壊する」ことだった。ハイブリッドシステムは、Triの各要素が「別の物理原理」に基づくため、連鎖崩壊が起きにくい。これはTTT理論の「交差項jJの分離」に相当する。

6. 実現への道 — 七つの段階

  1. 概念設計の統合
    トカマク（またはADS）+ 核変換ブランケット + DECの三層を、一つの系として概念設計する。各層のインターフェース（中性子スペクトル、熱負荷、材料互換性）を定義する。
  2. 既存実験データの統合読解
    JET・ITERの中性子産额データ、オメガ計画の核変換実験データ、神戸大学のDEC実験データ——これらをTTT式の変数として統合し、欠落変数を特定する。
  3. ブランケットのモジュール化設計
    hH（前歴）を管理するため、ブランケットは定期交換可能なモジュール構造にす。これにより「炉の寿命」問題が「モジュール交換」問題に変わる。
  4. DECの適用範囲の再定義
    D-T反応のDEC効率は限定的。核分裂生成物の荷電成分、ベータ線、ブランケット内のイオン化——どのDEC経路が実用的か、数値で評価する。
  5. システム全体のエネルギー収支モデル
    トカマク単体の「Q」ではなく、システム全体のエネルギー収支を定義する。入力：プラズマ加熱電力 + 補助系。出力：核変換熱 + DEC電力 + ブランケット熱（ランキンサイクル）。
  6. 安全性の多重バリア設計
    プラズマ停止系・ブランケット分離系・核種管理系——各層が独立して安全機能を持つ設計を行う。Tri構造の連鎖崩壊を防ぐ。
  7. 社会実装の構造読解
    この技術が「どこで」実装されるか。日本の使用済燃料のMAを処理する「核変換炉」として位置づけるなら、社会的受容性の問題がzZ（制度的チェック）として浮上する。reading-the-windの「司法・メディア・行政」のTri構造読解が、ここでも必要になる。

7. 結論 — 風は別の方向から吹く

「押した面（中心のプラズマ）とは反対側（外周の中性子）がどう変形するか」
— OOπ理論の出発点

トカマクを「炉」として読めば、風は破壊の方向に吹いている。しかし「中性子源」として読めば、風は核変換と直接電力変換の方向に吹いている。

これは「諦める」ことではなく、「読み直す」ことだ。磁場閉じ込め技術は無駄ではない。核分裂の知見も無駄ではない。直接電力変換の研究も無駄ではない。これらが別の風に見えたが、実際には一つの大きな風の中にある。

TTT理論で言えば、問題の定義（表面）を変えることで、裏面の変形パターンが変わる。トカマクの「失敗」は、一つの定義（炉としての核融合）の失敗に過ぎない。別の定義（中性子源としての核融合 + 核変換 + DEC）では、まったく異なる「予想」が立つ。

最終的に、この構想が実現するかどうかは、技術的変数だけでは決まらない。eE（外部圧力）としての国際政治、資金、社会的受容性がzZ（制度的チェック）を規定する。しかし、技術的に「できる」構造を読めたことで、議論の土台が変わる。これが「風を読む」の意味である。
