二つの陽子核が核力の届く距離（$\sim 1\ \text{fm}$）まで接近するには、

| 圧力（$n$） | 磁場閉じ込め・慣性閉じ込め |
| 閉じ込め時間（$\tau$） | ローソン条件の最適化 |

## 2. TTT 理論的基盤

### 2.1 双極ゼロ（00）とは

TTT 理論の中核概念である双極ゼロ（$Y = 1/X$ 理論より）：

$$\lim_{X \to 0^+} \frac{1}{X} = +\infty, \quad \lim_{X \to 0^-} \frac{1}{X} = -\infty$$

ゼロは「無」ではなく、**正と負の動的均衡点**である。  
この均衡点に形成される安定極小が「00ポテンシャル井戸」である。

### 2.2 正四面体の 00 条件

4つの単位ベクトルが正四面体の頂点方向を向くとき：

$$\mathbf{k}_1 + \mathbf{k}_2 + \mathbf{k}_3 + \mathbf{k}_4 = \mathbf{0}$$

これが **00 構造**（ベクトル総和ゼロ）の幾何的実体である。

### 2.3 He-4 との対応

核融合の主生成物である He-4 は：
- 2陽子 + 2中性子
- 核子が正四面体配置（$T_d$ 対称性）を持つ
- 魔法数核（$Z=2, N=2$）の超安定構造

**TTT 予測：He-4 の正四面体構造は偶然ではなく、00 構造の物理的必然である。**

## 3. 波動干渉による 00 ポテンシャル生成

### 3.1 4方向波の干渉場

$$E(\mathbf{r},t) = \sum_{i=1}^{4} E_0 \cos(\mathbf{k}_i \cdot \mathbf{r} - \omega t + \phi_i)$$

**正四面体条件（位相同期）：**

$$\mathbf{k}_1 + \mathbf{k}_2 + \mathbf{k}_3 + \mathbf{k}_4 = \mathbf{0}, \quad \phi_1 = \phi_2 = \phi_3 = \phi_4$$

この条件下で干渉場は正四面体対称の節点構造を形成する。

### 3.2 エネルギー密度

$$u(\mathbf{r}) = \frac{\varepsilon_0}{2} \langle |E(\mathbf{r},t)|^2 \rangle_t$$

時間平均後、節点位置に **エネルギー密度の極小** が現れる。

### 3.3 有効ポテンシャルへの写像

$$V_{\text{wave}}(\mathbf{r}) = -\lambda\, u(\mathbf{r})$$

ここで $\lambda > 0$ はプラズマ-波動結合定数。  
節点が $R = R_{\text{He}}$（He-4 核子間距離）に一致するとき：

$$V_{\text{wave}}(R) \approx \frac{1}{2}k_{00}(R - R_{\text{He}})^2 - V_{00}$$

$V_{00} > 0$ が 00 ポテンシャル井戸の深さを表す。

## 5. トンネル確率の解析

### 5.1 WKB 近似

$$P \approx \exp\!\left[ -\frac{2}{\hbar} \int_{R_1}^{R_2} \sqrt{2\mu\bigl(V(R) - E\bigr)}\; dR \right]$$

- $\mu$：換算質量
- $R_1, R_2$：転回点（$V(R_i) = E$）
- $E$：入射粒子のエネルギー

### 5.2 00 ポテンシャルの効果

00 ポテンシャルの追加により：

1. **転回点の変化**：$R_2$ が内側にシフト → 障壁幅 $(R_2 - R_1)$ 縮小
2. **実効障壁高さの低下**：$V_{\text{max}} \to V_{\text{max}} - V_{00}$
3. **結果**：WKB 指数の絶対値が減少 → $P$ が **指数関数的に増大**

$$\Delta \ln P \approx \frac{2}{\hbar} \int_{R_1'}^{R_2'} \sqrt{2\mu V_{00}}\; dR > 0$$
