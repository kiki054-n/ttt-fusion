## 概要

本実験は、TTT-Fusion 理論が予測する「正四面体配置 ICRH による核スピン Td 対称モード励起」の効果を、既存のトカマクまたは小型プラズマ装置を用いて最小コストで検証するものである。

**核心的予測:**
正四面体配置（4方向）の ICRH 照射は、通常配置と比較して重水素核スピンの偏極度・配向対称性に有意な差異をもたらす。この差異は核融合反応率に最大 25% の向上をもたらすことが期待される（核スピン効果のみ）。

## 1. 実験の背景と理論的根拠

### 1.1 TTT-Fusion の核心命題

TTT 理論（Tri-Tetra Theory, Y=1/X 公理）は、OOO（双極ゼロ）構造を持つ4方向位相同期波の照射によって正四面体節点に 00 ポテンシャルが形成され、WKB トンネル確率が増大すると予測する。

A+B 統合戦略（経路 A: ICRH 核スピン秩序化 × 経路 B: 正四面体 RF 干渉）では：

```
λ_eff = λ_A × λ_B = 10³ × 16 ≈ 1.6 × 10⁴
```

### 1.2 核スピン緩和の定量的計算（今回の理論的根拠）

| パラメータ | ITER相当 (10 keV) | 小型装置 (1 keV) |
|---|---|---|
| T₁（ICW結合・支配的） | 1.5 × 10⁴ s（≈4時間） | 5.5 × 10⁴ s |
| T₂*（磁場不均一性） | 4.9 μs | 8.1 μs |
| 実効時間窓 T_window | **4.9 μs** | **8.1 μs** |
| 必要な B_RF（臨界値） | 76 mT | 46 mT |
| 推奨 B_RF | 100 mT | 80 mT |
| 定常偏極度 P_ss（100 mT 時） | 0.71 | 0.71 |
| 期待される反応率向上 | +18% | +18% |

**重要な発見:** T₁ ≈ 4時間は実用上「無限大」。真の制限は磁場不均一性による T₂* = 4.9 μs であり、B_RF ≧ 76 mT（ICRH 通常動作範囲内）で克服可能。

### 1.3 μCF との比較による理論的妥当性

| | μCF | TTT-Fusion |
|---|---|---|
| スティッキング率 | ω_s = 1.2% | τ_fuse/T₁ = 6.5×10⁻¹³（事実上ゼロ） |
| Q値問題 | あり（μ生成コスト > 出力） | なし（電磁場は⁴He に捕捉されない） |
| 実験状況 | 実証済み（1989年〜） | 本実験が最初の検証 |

## 2. 実験目的

### 主目的
正四面体配置 ICRH が、通常配置と比較して重水素プラズマの核スピン偏極度を有意に増大させることを測定する。

### 副目的
1. 核スピン偏極度と核融合中性子収量の相関を測定する
2. 正四面体対称モード（Td）の励起を核磁気共鳴（NMR）的手法で確認する
3. 位相同期の有無による偏極度の差異を定量化する

### 3.1 プラズマ装置（既存装置の転用を想定）

| 項目 | 最小要件 | 推奨値 |
|---|---|---|

| プラズマ密度 n | ≧ 10¹⁸ m⁻³ | 10¹⁹〜10²⁰ m⁻³ |

### 3.2 ICRH サブシステム（本実験の核心）

#### フェーズ1実験（概念実証、最小構成）

```
アンテナ配置: 2方向対向（従来型）vs 4方向正四面体
              ↓ 対照実験
              フェーズ1では2方向 vs 4方向の比較のみ
```

| 項目 | 仕様 |
|---|---|
| ICRH 周波数 | f = γ_D × B₀ / 2π（D 核ラーモア周波数） |
| B₀ = 3 T 時 | f_D = 19.6 MHz |
| B₀ = 5 T 時 | f_D = 32.7 MHz |
| RF 磁場強度 B_RF | **≧ 76 mT**（臨界値）、推奨 100 mT |
| アンテナ数 | 4基（正四面体配置）|
| 位相制御精度 | Δφ ≦ 0.1 rad |
| ICRH 電力 | 0.1〜1 MW |

#### 正四面体アンテナ配置の設計

```
       ●アンテナA（上）
      /|\
     / | \
    /  |  \
●B  ─ ─  ●C   ← XY平面（Z=0）に3本
    \  |  /
     \ | /
      \|/
       ●D（下）

位相条件: φ_A + φ_B + φ_C + φ_D = 0
          各アンテナ間位相差 = 90° × (正四面体回転角)
波数ベクトル: Σ k_i = 0（OOO条件）
```

### 3.3 計測システム

#### 核スピン偏極度の測定

| 手法 | 原理 | 期待感度 |
|---|---|---|
| **NMR 吸収分光** | 核スピン集団の共鳴吸収強度 | ΔP/P ≧ 1% |
| **中性子偏極解析** | D-D 反応中性子のスピン非対称 | 非対称度 A ≧ 0.01 |
| **シンクロトロン X 線** | 核スピン起源の磁気散乱 | （大型施設向け） |
| **光学偏極測定（OPM）** | 核スピン⇄電子スピン結合 | ΔP ≧ 0.1%（高感度） |

**推奨第一手法: NMR 吸収分光**
既存 ICRH 装置の受信回路を改造することで実装可能。追加コストが最小。

#### 核融合反応率の測定

- D-D 中性子収量: 2.45 MeV 中性子の絶対計数（シンチレータ）
- D-D ガンマ線: 核融合由来 γ 線スペクトル
- 対照実験比較: 正四面体配置 vs 非正四面体配置での中性子収量比

## 4. 実験手順

### フェーズ1：概念実証（6ヶ月）

**目的:** 正四面体配置 vs 通常配置で核スピン偏極度に差異が生じることを確認する

```
Step 1: ベースライン測定（通常ICRH）
  - 通常の2方向または環状アンテナ配置で運転
  - NMR 吸収分光で核スピン偏極度を測定
  - D-D 中性子収量を記録

Step 2: 正四面体配置 ICRH 実験
  - 4基アンテナを正四面体配置に設置
  - ICRH 周波数を D 核ラーモア周波数に設定
  - 位相を 4波の Σk_i = 0 条件に調整
  - B_RF = 100 mT で照射開始

Step 3: 偏極度測定（B_RF 掃引）
  - B_RF: 10 mT → 20 → 50 → 76（臨界） → 100 mT
  - 各点で NMR 吸収強度と中性子収量を記録
  - τ_ord/T₂* < 1 の成立を確認

Step 4: 位相制御実験
  - 正四面体位相（Σk_i=0）vs ランダム位相 vs 逆位相
  - 3条件での偏極度・中性子収量の差異を測定
```

### フェーズ2：定量評価（6ヶ月）

**目的:** 核スピン偏極による反応率向上を定量的に測定する

```
Step 5: 温度・密度依存性
  - T: 0.5, 1, 5, 10 keV での各測定
  - n: 10¹⁸〜10²⁰ m⁻³ での各測定
  - λ_A の実測値を計算値と比較

Step 6: 定常偏極の確認
  - ICRH 連続照射下での P_ss の時間発展を測定
  - 計算予測 P_ss ≈ 0.71（B_RF=100 mT）と比較

Step 7: A+B 統合実験（経路 B との組み合わせ）
  - 正四面体 ICRH（A）+ 140 GHz 正四面体 RF（B）の同時照射
  - λ_eff_combined ≈ 1.6×10⁴ の効果を確認
```

### フェーズ3：実証（12ヶ月）

**目的:** Q > 1 を目指した統合システムでの検証

```
Step 8: 全統合実験
  - A+B 統合戦略を最適条件で運転
  - 期待される中性子収量向上: ×100〜×10,000
  - プラズマ Q 値の改善を測定

Step 9: スケールアップ評価
  - 実験結果を ITER 相当にスケールアップする計算
  - TTT-Fusion の実用化シナリオの策定
```

## 5. 期待される測定値と判定基準

### 成功判定基準

| 測定項目 | 帰無仮説（効果なし） | TTT 予測値 | 成功基準 |
|---|---|---|---|
| 核スピン偏極度 P | P ≈ 0（熱平衡） | P_ss ≈ 0.71 | P ≧ 0.1（5σ以上） |
| 中性子収量向上（A のみ） | 比率 = 1.00 | 比率 ≈ 1.18 | 比率 ≧ 1.05（3σ以上） |
| 中性子収量向上（A+B） | 比率 = 1.00 | 比率 ≧ 100 | 比率 ≧ 2（2σ以上） |
| 位相依存性 | 差異なし | 正四面体 > ランダム > 逆位相 | 順序の確認 |
| T₂* の実測値 | — | 4.9 μs（計算値） | 実測値との一致 |

### 否定的結果の場合

- 偏極度に有意差がない場合: λ_A の上限値を更新し理論を修正
- 位相依存性がない場合: 正四面体条件（Σk_i=0）の実現を再検討
- T₂* が計算より短い場合: 追加の緩和機構を特定・模型に組み込む

## 9. 本実験の理論的意義

### TTT 理論体系との接続

本実験は以下の TTT 公理を物理実験として検証する：

| TTT 公理 | 検証される予測 |
|---|---|
| 第2公理（XY平面 ±1 の双極） | 正四面体配置（Σk_i=0）が特別な対称性を持つ |
| 第6公理（5の普遍性） | ⁴He の正四面体構造への収束が ICRH で促進される |
| 第5公理（Link α） | 核スピン秩序化が「時間の矢」を核融合過程に与える |
| 補遺A（λ_A 経路） | ICRH 正四面体配置で λ_A ≈ 10³ が実現される |

### μCF との関係

本実験は、μCF（実証済み）と TTT-Fusion（理論提案）の橋渡しとなる。
μCF が「距離の縮小」で核融合を促進するのと双極的に、
TTT-Fusion は「エネルギーの等価増大」で同じ目標を達成する。
