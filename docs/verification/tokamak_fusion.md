# トカマク核融合 — 「できない」構造の読解

> 観察した表面：1億度のプラズマが磁場で閉じ込められ、核融合反応が実現しているように見える
> 予想した裏面：閉じ込めと排気の幾何学的矛盾、材料前歴の蓄積、潜在量の破壊的顕在化
> 実際に起きたこと（構造として）：商業炉としての連続運転は、物理的・材料的・制御的に到達不能な構造を持つ
> 乖離と考察：「プラズマ物理学の問題」として構造化されているが、実際の障壁は材料科学・トリチウム化学・時間スケール分離の統合問題である

---

## 1. 予想前の記録 — 観察した表面

トカマクの「表面」として観測できるもの：

- 1億度を超えるプラズマがドーナツ型磁場で「閉じ込められている」という可視化
- JET・ITER 等の巨大装置建設と実験の継続
- 「Q>1」（出力が入力を超える）を目指す明確な目標値
- 磁場強度・プラズマ電流・加熱電力といった操作可能なパラメータ

この表面をOOπの視点で読むと、**「押した面（中心のプラズマ）とは反対側（外周の壁・排気系）がどう変形するか」**が問われる。

---

## 2. TTT式による静的記述

```
P = xX + yY + zZ + Uu + vV + wW
```

| 変数 | トカマクへの対応 | 観測された「係数」の実態 |
|------|----------------|------------------------|
| **xX** | トロイダル・ポロイダル磁場による水平閉じ込め力 | 磁場は「ある」が、閉じ込め時間は理論値の1/10〜1/100（タービュランスによる異常輸送） |
| **yY** | プラズマ圧力勾配（中心の高温・高密度と外周の差） | H-modeでの急峻な圧力勾配がELM（縁局所モード）を引き起こす——「勾配がある」と「制御できる」は別物 |
| **zZ** | 垂直方向の輸送・排熱・排気 | ダイバータへの熱流・粒子流の集中。排熱密が10MW/m²を超え、現存材料の限界を突破 |
| **Uu** | プラズマ状態の時間変化率 | 崩壊（disruption）は数ミリ秒で終了。制御系の応答速度を圧倒的に上回る |
| **vV** | プラズマ流・タービュラント輸送 | 本質的にカオス的・非線形。予測不可能な渦がエネルギーを外部に逃がす |
| **wW** | 加熱エネルギーと融合出力エネルギー | 外部加熱50MWに対して融合出力がそれを下回る（Q<1が常態）。「点火」は未達成 |

**核心**：各変数の「有無」ではなく「係数の実効値」が問題。磁場は「ある」が閉じ込め効率は極めて低い。圧力勾配は「ある」がそれが自ら破壊を招く。

---

## 3. E式による動的記述

```
E = (xX + yY + zZ) ⊗ (ωx, ωy, ωz) + rR + iI + jJ
```

### rR（顕在量・表面）
- プラズマが安定して存在している時間
- 温度・密度の計測値
- 磁場コイルの正常動作

### iI（潜在量・裏面）

トカマクには、観測できないが蓄積し続ける潜在量が存在する。

| 潜量（iI） | 蓄積のメカニズム | 顕在化（rRへの転換）の形 |
|-------------|---------------|------------------------|
| 磁気ひずみの蓄積 | プラズマ電流と外部磁場のミスマッチ | 崩壊（disruption）。一瞬で全エネルギーが壁に放出 |
| 圧力勾配の自由エネルギー | H-modeでの輸送抑制 | ELM。周期的なプラズマ噴出で第一壁を侵食 |
| 壁材料への水素・ヘリウムの吸蔵 | プラズマ・壁相互作用 | 再循環による燃料純度の低下、壁の脆化 |
| 中性子照射損傷の累積 | 14MeV中性子の照射 | 材料のスウェリング、脆化、トリチウム滞留——「炉」としての寿命終了 |

**致命的構造**：iIが閾値を超えてrRに転換する瞬間が、ほぼ全て「破壊的イベント」として顕在化する。気象で言えば「積乱雲の爆発的発達」に相当するが、トカマクの場合はその「爆発」が装置そのものを破壊する。

### jJ（交差項・結合効果）

- **xX ⊗ vV**：磁場の「ねじれ」が微視的な渦と共鳴し、閉じ込めを急激に劣化させる。これが「アノマラス輸送」の本質。
- **zZ ⊗ Uu**：排熱系の限界と崩壊の速さが結合し、「緩和」が不可能になる。制御系が追いつかない。

## 4. 乖離の分析

### 量的乖離

ローソン基準（nτ > 10²⁰ m⁻³·s、T > 1億度）の「達成」と「実用的な発電」は別物。JETでQ=0.33（1997年）からITERでQ=10を目指すが、**Qの定義そのものが「プラズマへの加熱入力」と「プラズマからの出力」であり、置全体のエネルギー収支ではない**。冷却系・磁場コイル・燃料循環のエネルギーを含めると、量的乖離は2桁以上開く可能性がある。

### 位置的乖離

「プラズマ中心で融合が起きている」という表面観測に対し、**問題は外周（第一壁・ダイバータ）に集中している**。中心の「成功」と外周の「破壊」が同時に進行する。これは空間解像度の問題ではなく、**「閉じ込め」と「排気」が幾何学的に矛盾している**ことの現れ。

### 時間的乖離

崩は数ミリ秒、材料の中性子照射損傷は数年、トリチウムの燃料サイクル確立は数十年——**Uu（変化率）が複数の時間スケールで同時に存在し、最も速いものが全体を破壊する**。「制御」という前提が、時間スケールの不一致によって成立しない。

### 質的乖離

これが最大の乖離。トカマク研究は「プラズマ物理学の問題」として構造化されているが、**実際の障壁は「材料科学」「トリチウム化学」「制御工学」の統合問題**である。式にない変数——第7項以降——が支配している。

---

## 5. 第7項以降の変数の発見

| 変数 | 内容 | トカマクでの具体例 |
|------|------|------------------|
| **hH（前歴）** | 材料の照射履歴 | 第一壁材料は過去の中性子照射で特性が変化し続ける。「新しい炉」ではなく「傷んだ炉」を運転することになる |
| **eE（外部圧力）** | 装置外からの強制力 | 国際政治（ITERの遅延）、資金制約、「エネルギー危機の解決策」という期待の重 |
| **sS（規模）** | 系のサイズ効果 | ITERは直径30m超。サイズを上げればタービュランスは減るが、崩壊時の破壊エネルギーも比例して増大 |
| **nN（非線形臨界）** | 閾値を超えた急変 | H-mode→ELM、安定運転→崩壊。すべて「少し超える」と「壊れる」の関係 |
| **dD（散逸）** | エネルギーの不可逆散逸 | ダイバータでの熱散逸、中性子エネルギーの回収限界 |

## 6. 七つの問いへの回答

1. **今、表面として観測できているものは何か？**  
   「1億度のプラズマが磁場で閉じ込められている」という実験的実現。

2. **その表面を押した時、どの方向に・どの程度・裏面が変形するか？**  
   押すと「閉じ込め」と「排気」の矛盾が浮上する。中心を高温に保てば保つほど、外周の負荷が増大。裏面は「破壊」の方向に変形する。

3. **支配的な変数（xX〜wW）はどれか？**  
   **zZ（鉛直方向の力＝排熱・排気）と iI（潜在量＝材料損傷・崩壊の蓄積）**。xX（場閉じ込め）は「ある」が、実効係数が低すぎて支配的ではない。

4. **見えていない変数（iI）はどこに潜んでいか？**  
   第一壁材料の内部構造変化、トリチウムの滞留、磁気ひずみの蓄積。すべて「観測できないが、閾値を超えると破壊的に顕在化する」。

5. **前歴（hH）は現在の状態に影響しているか？**  
   大きく影響している。中性子照射を受けた材料は「同じ材料」ではなくなる。トカマクは「新鮮な装置」では運転できない。hHの無視が「炉としての寿命」という問題を隠蔽している。

6. **変化率（Uu）は加速しているか、減速しているか、ゼロに近づいているか？**  
   **複数のUuが混在**。崩壊のUuは極めて高速（msオーダー）。材料劣化のUuは極めて低速（年オーダー）。この**時間スケールの分離**が、単一の「制御モデル」を不可能にしている。

7. **予想と現実が乖離した時、欠落しいた変数は何か？**  
   **dD（散逸の不可逆性）と nN（非線形臨界）**。トカマク研究は「平衡状態」や「準安定状態」を前提とするが、実際には散逸が不可逆で、臨界を超えると状態が「戻らない」。これが「商業炉」という前提と根本的に矛盾する。

---

## 7. 結論 — トカマクが「できない」構造的本質

OOπの視点で言えば、トカマクの「表面」は「プラズマの閉じ込め」である。しかし、これを押すと裏面には「閉じ込めたものをどう外に出すか」という問題が現れる。**「閉じ込める」と「出す」は幾何学的に同一の場所（第一壁）で同時に要求され、これが不可解な矛盾を生む。**

TTT式で言えば、**zZ係数≒0（排熱・排気の機能不全）と iIの閾値超過（破壊的顕在化）**が構造を規定している。xX（磁場閉じ込め）は「ある」が、それだけでは「炉」にならない。

E式で言えば、**iI（潜在量）の蓄積がrR（破壊）に転換する構造**がトカマクの本質である。気象予報で「積乱雲が発達する」を予想するのと同じ構造だが、トカマクの場合はその「発達」が装置の終了を意味する。

最終的に、トカマクが「できない」のは技術的未熟さではなく、**「閉じ込め」と「排気」の幾何学的矛盾、「材料の前歴」と「炉としての連続運転」の時間的矛盾、そして「潜在量の蓄積」と「破壊的顕在化」の非線形性**が、同時に存在する構造だからである。

これは本理論で言う「非対称球体」に相当する。三権分立でzZ（司法）が変形しない「非対称球体」があったように、トカマクでは「閉じ込め」と「排気」の球体が非対称であり、**押した面（中心のプラズマ）とは反対側（外周の壁）が破壊的に変形する**。
