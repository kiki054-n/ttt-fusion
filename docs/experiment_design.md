## 1. 正四面体波源配置の幾何学

### 1.1 4方向単位ベクトル（正四面体頂点方向）

$$\hat{k}_1 = \frac{1}{\sqrt{3}}(1, 1, 1)$$
$$\hat{k}_2 = \frac{1}{\sqrt{3}}(1, -1, -1)$$
$$\hat{k}_3 = \frac{1}{\sqrt{3}}(-1, 1, -1)$$
$$\hat{k}_4 = \frac{1}{\sqrt{3}}(-1, -1, 1)$$

検証：$\hat{k}_1 + \hat{k}_2 + \hat{k}_3 + \hat{k}_4 = \mathbf{0}$ ✅

### 1.2 干渉節点の位置

波数 $k = 2\pi/\lambda$ として、干渉節点は：

$$\mathbf{r}_{\text{node}} = \frac{n\lambda}{\sqrt{2/3}} \hat{e}_i \quad (n \in \mathbb{Z})$$

## 2. トカマク への適用

### 2.1 配置案

```
         波源1（上）
            ↓
波源2 → プラズマ ← 波源3
（前左）         （前右）
            ↑
         波源4（下後）
```

正四面体の重心 = プラズマ中心

### 2.2 推奨パラメータ

| パラメータ | 推奨値 | 備考 |
|---|---|---|
| 周波数 | 28 GHz または 60 GHz | ECRH 帯域 |
| 電場強度 | $10^5 \sim 10^7$ V/m | プラズマ密度に依存 |
| 位相精度 | $\Delta\phi < 0.1\ \text{rad}$ | 節点形成の条件 |
| アンテナ間距離 | $\sim \sqrt{6}/2 \cdot a$（$a$：トーラス小半径） | 正四面体配置 |

### 2.3 測定プロトコル

1. 通常運転（波源なし）で D-T 反応率 $R_0$ を測定
2. 4方向波源を順次追加（1→2→3→4）
3. 各段階で反応率 $R_i$ を測定
4. 位相差 $\Delta\phi$ を掃引して 00 条件の極大を探索
5. 目標：$R_4 / R_0 > 1.5$（統計的有意）

## 3. ICF（レーザー核融合）への適用

### 3.1 配置案

既存の多方向レーザー系（NIF 型）において、  
192本のビームから4本を選び正四面体配置。

残り188本は従来の球対称圧縮に使用。

### 3.2 タイミング制御

```
t = 0        ns : 球対称圧縮ビーム開始
t = T_stag   ns : 4方向正四面体ビーム投入（点火直前）
t = T_ignit  ns : 点火
```

$T_{\text{stag}}$ の最適化が核心的パラメータ。

### 3.3 波長選択

| 波長 | 理由 |
|---|---|
| 351 nm（UV） | プラズマ透過性・吸収効率 |
| 527 nm（緑） | 既存 NIF システムとの互換 |

## 4. 正20面体配置（拡張実験）

### 4.1 20方向単位ベクトル

正20面体の頂点方向（12頂点を正規化）：

$$\hat{k}_i \in \left\{ \frac{1}{\sqrt{1+\phi^2}}(\pm 1, \pm\phi, 0),\ \text{cyclic} \right\}$$

ここで $\phi = (1+\sqrt{5})/2$（黄金比）。

### 4.2 期待効果

正20面体配置は 00 節点の空間密度を増加させ、  
プラズマ全体にわたる反応率向上が期待される。

## 5. 測定・観測手法

### 5.1 00 節点の可視化

| 手法 | 測定対象 |
|---|---|
| トムソン散乱 | 電子密度・温度の空間分布 |
| マイクロ波干渉計 | 密度節点の位置 |
| 中性子飛行時間法 | D-D / D-T 反応の空間分布 |

### 5.2 期待される観測シグネチャ

- 電子密度の空間分布に正四面体対称の節点構造
- 中性子発生の空間分布が正四面体対称に集中
- 位相 $\Delta\phi = 0$（00 条件）で反応率が極大
